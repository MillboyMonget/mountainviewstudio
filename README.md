# Mountain View Studio (web)
Host on GitHub Pages: create a repo, upload index.html + renderer.js to the root,
then Settings > Pages > Deploy from branch > main / root. Open the URL it shows.
Save = downloads a .mvstudio file; Open = pick that file. Export menu: GLB, OBJ, STL, USDZ.

New: History tab (every edit is a version; click to restore; star = named version, saved inside project files) and a Texture picker (wood, dark wood, brick, stone, concrete, plaster, tile, slate, metal).
